# 🗣️ Real-Time AI-Powered Conversational English Tutoring Assistant - Frontend

A responsive, mobile-first client application built with React, TypeScript, and Vite, designed to deliver fluid real-time voice interactions and low-latency audio streaming with an AI tutor.

---

## ✨ Key Features

- 🎙️ **Real-Time Audio Capture** — Integrated browser-based audio recording to capture user voice input and stream data seamlessly.
- ⚡ **Low-Latency UI Rendering** — Optimized asynchronous state management and real-time event handling for interruption-free voice sessions.
- 📱 **Modern & Responsive Interface** — Clean, adaptive layout designed using Tailwind CSS across both mobile and desktop viewports.
- 🚀 **Vite Build Performance** — Powered by Vite and TypeScript for lightning-fast module reloading and type-safe component development.

---

## 🛠 Tech Stack

- **Framework:** React
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
